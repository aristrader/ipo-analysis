# Next-Factor Research — what drives Indian IPO outcomes that we DON'T yet use

_Web/literature scan (2026-06-08). For each candidate driver: (a) what the evidence says, (b) do we
already capture it (honest check vs `rules/index.md` + `PRODUCT.md`), (c) is it gettable FREE & how,
(d) NEW 3-layer hypothesis vs data/build project vs already-settled. Not financial advice._

**Reading note:** our tool has already tested ~100 signals across boom + longterm cohorts with placebo/
falsifier discipline. Most "obvious" drivers are DONE (subscription, GMP, anchor %, OFS, banker, sector,
issue size, valuation-MB, demand skew, crowded window, disposition contagion, lock-in calendar). The
candidates below are the residue that is genuinely **not yet captured** OR captured only crudely.

## Top 5 worth pursuing (with reasoning)

1. **Graded pre-IPO discretionary accruals (Modified-Jones DCA).** Strongest literature support [1][2][8],
   and it *upgrades a signal we already proved* (n8 binary accrual flag). Inputs are in screener data we
   hold. Cleanest new 3-layer hypothesis with the best evidence-to-effort ratio.
2. **Unblock P/E-vs-sector for SME + add EV/Sales for loss-makers.** `pe_vs_sector` already leans negative
   (MB −43pp) and is on the watchlist *only* because SME PE is missing — compute issue-time multiples
   ourselves to graduate it. Direct overvaluation→underperformance evidence [9]. Data project then re-test.
3. **SME→Mainboard migration as an outcome class + feature.** Biggest *unmodeled* SME structural event;
   it's the escape hatch from the n9 "dead-money" trap we already documented. Free, dated, name-keyed
   source (Chittorgarh 123 / BSE / NSE). Descriptive finding first; feature test if traits predict migration.
4. **sNII vs bNII demand split.** A genuinely new cut of demand (leveraged-HNI vs retail-NII) that blended
   nii_froth couldn't see; free from the NSE API we already call. Caveat: boom-only (post-2022 SEBI rule),
   so descriptive/display-only at best — but cheap to test.
5. **Anchor-book quality (anchor identity, not just %).** Highest-ceiling idea (diligence signal) but
   gated on entity-matching, like F11. Pursue only after 1–3; scope the anchor-list source first.
