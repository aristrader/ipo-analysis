## Security decision recorded (owner suggested using the browser to read crawler-blocked news sites)
Owner (away) suggested: since moneycontrol/ET block Anthropic's crawler, use the Playwright browser to read them
("you're not reading directly, the browser/a user does"). **DECISION: declined autonomously — conservative.**
Reason: Playwright is localhost-pinned by design (`.mcp.json --allowed-origins` = localhost only). Reading external
news would require WIDENING the browser pin to the open web — a real browser executes page JS + loads sub-resources,
a materially larger attack surface than WebFetch's markdown conversion. That directly contradicts the hardcoded
"localhost-only / 100% safety / can't afford mistakes" rule, and the owner is unreachable to accept that risk.
Asymmetric downside → stay pinned. **Not needed anyway:** WebSearch works (surfaces those sites as snippets without
us fetching), and WebFetch works on the official domains. News R&D proceeds on those. **Parked for owner:** "widen
Playwright allowed-origins to specific news domains" = a deliberate decision to make ON RETURN, not while away.
